# Notes

Analysis and literature checks that are **not** bench procedures. Dated, one topic per file. Anything here that becomes a decision gets folded into the relevant protocol in [`../protocols/`](../protocols/README.md).

**Our stack, when reading any of this:** `graphene → π-stacked pyrene → amide ← 5′-amine DNA`. There is no DNA on the graphene. Citations are labelled **A** (DNA adsorbed directly on carbon — an upper bound only), **B** (DNA covalently tethered through PBASE — our chemistry), **C** (DNA on another SAM, e.g. thiol-DNA on gold — the nearest analogue, not yet reviewed).
